# Bundled Free Duel portraits

The 39 PNG files in this directory are 48 x 48 in-game mugshots from the original PlayStation release of Yu-Gi-Oh! Forbidden Memories. They are mapped to the game's Free Duel opponent IDs 1 through 39.

Source sheet: https://www.spriters-resource.com/playstation/ygofm/asset/51205/

Sheet uploader: The Spriters Resource user Phongpon. The source sheet SHA-256 and every numbered PNG checksum are recorded in `manifest.json`. The ID mapping was cross-checked against https://yugioh-fm-db.pages.dev/duelists before packaging.
